# Тарифы Сорока CRM для Казахстана

Действуют с 1 марта 2026 года для клиентов, заключивших договор с ТОО «Сорока Софт Казахстан». Цены указаны в тенге за месяц за всю команду при помесячной оплате и включают НДС 12%.

## Тариф «Старт» (Казахстан)

Тариф «Старт» для Казахстана рассчитан на команды до 5 пользователей. Стоимость — 7 900 ₸ в месяц. В тариф входят 10 ГБ файлового хранилища и одна воронка продаж. API и интеграции недоступны.

## Тариф «Команда» (Казахстан)

Тариф «Команда» для Казахстана рассчитан на команды до 20 пользователей. Стоимость — 26 900 ₸ в месяц. В тариф входят 100 ГБ файлового хранилища и до 10 воронок продаж. Доступен REST API с лимитом 60 запросов в минуту.

## Тариф «Бизнес» (Казахстан)

Тариф «Бизнес» для Казахстана рассчитан на команды до 100 пользователей. Стоимость — 69 900 ₸ в месяц. В тариф входят 500 ГБ файлового хранилища, неограниченное количество воронок продаж, REST API с лимитом 300 запросов в минуту и журнал аудита. Интеграция с 1С для казахстанских клиентов доступна с тарифа «Бизнес».

## Тариф «Корпоративный» (Казахстан)

Тариф «Корпоративный» для Казахстана стоит от 159 000 ₸ в месяц за 250 пользователей. Условия по хранилищу, API и персональному менеджеру совпадают с российским тарифом «Корпоративный».

## Пробный период (Казахстан)

Для клиентов из Казахстана пробный период тарифа «Бизнес» составляет 7 дней. По запросу менеджер может продлить его ещё на 7 дней один раз. Данные после окончания пробного периода хранятся 30 дней.

## Оплата для клиентов из Казахстана

Оплата принимается в тенге банковской картой или по счёту. Электронный счёт-фактура выставляется через информационную систему ЭСФ в течение 15 календарных дней после оказания услуг. Оплата в рублях для клиентов из Казахстана не принимается.
