# Поддержка клиентов

## Каналы поддержки

Поддержка доступна через чат в интерфейсе Сервиса и по электронной почте support@soroka-crm.example. Поддержка по телефону доступна только клиентам тарифов «Бизнес» и «Корпоративный». Клиентам тарифа «Корпоративный» также выделяется персональный менеджер с прямым контактом в мессенджере.

## Часы работы поддержки

Поддержка для клиентов из России работает с понедельника по пятницу с 9:00 до 18:00 по московскому времени. Поддержка для клиентов из Казахстана работает с понедельника по пятницу с 9:00 до 18:00 по времени Астаны. В праздничные дни поддержка работает в режиме дежурства и принимает только обращения P1. Круглосуточная поддержка предоставляется только по обращениям P1 на тарифе «Корпоративный».

## Языки поддержки

Поддержка ведётся на русском языке. Клиентам из Казахстана поддержка доступна также на казахском языке. Поддержка на английском языке предоставляется только клиентам тарифа «Корпоративный».

## Обучение

Еженедельные обучающие вебинары бесплатны для всех клиентов, включая пробный период. Персональное онбординг-обучение длительностью 2 часа включено в тариф «Бизнес» при оплате на год. На тарифе «Корпоративный» включено до 10 часов персонального обучения. Дополнительный час персонального обучения стоит 4 500 ₽.

## База знаний и статус сервиса

Статьи базы знаний и видеоинструкции доступны без авторизации. Текущий статус Сервиса и история инцидентов публикуются на странице статуса; подписаться на уведомления об инцидентах можно по электронной почте.
