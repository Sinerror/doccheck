# Памятка для отдела продаж: SLA и поддержка

Используйте эти формулировки в переписке с клиентами.

На тарифе «Команда» гарантированная доступность сервиса составляет 99,5% за календарный месяц.

На тарифе «Бизнес» время первой реакции на обращение P1 составляет 1 час.

Время реакции по SLA — это гарантированное время, за которое проблема будет решена.

Компенсация за недоступность выплачивается деньгами на расчётный счёт клиента.

Компенсация не может превышать 50% месячной стоимости тарифа.

Плановые технические работы проводятся по субботам с 02:00 до 05:00 по московскому времени.

Круглосуточная поддержка по любым обращениям доступна клиентам тарифов «Бизнес» и «Корпоративный».
